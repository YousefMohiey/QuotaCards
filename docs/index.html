What it does

Your ISP reads the TLS handshake at the start of a connection to decide which quota it counts against. QuotaVPN puts a server name from the package you chose on that handshake.

Counts against the package you pick

Gamerz and Streamerz profiles each carry their own server list, so a game or a stream rides the package that should pay for it instead of your general quota.

Three transports, clearly labelled

Standard, WireGuard and Hysteria2. Each one says in plain words what it spends from, because a faster mode that counts differently is a decision, not a detail.

Per-app routing

Send the whole device through the tunnel, only the apps you list, or everything except them. The choice is per card and it survives restarts.

It updates itself

One installer per platform, no admin needed on Windows, and the app keeps itself current from the releases page. The APK sideloads once and does the same.

How it works

The same engine on both platforms: sing-box, with wintun on Windows and VpnService on Android. Traffic goes through the tunnel or nowhere.

Every profile carries its own servers

A card is a profile: a name, a domain to ride, the transport, and a server list you can extend with your own address at any time.

Questions

What does QuotaVPN actually change?

Your ISP decides which quota a connection counts against from the TLS handshake at its start. QuotaVPN gives each connection a server name from the package you picked, so the session lands in that bucket instead of your general quota.

Does it work with any ISP?

It is built for ISPs that sell your line in quota buckets, where gaming, streaming and general traffic are counted separately. On a normal line it still works as a plain VPN.

Do I need an account?

No. There is no sign up and no account. You add the server address and the profile your server gives you, and the app connects.

Is the Android build a real app or a wrapper?

It is a native VpnService app with the same Rust core as the Windows build, including per-app routing, a Quick Settings tile and Always-on VPN support.
