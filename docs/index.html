What it does

One engine, two apps, and a routing table that decides which quota a session lands in.

Quota class
Counts against the package you pick

Gamerz and Streamerz profiles each carry their own server list, so a game or a stream rides the package that should pay for it instead of your general quota.

Valorant voice
Voice chat, when your region blocks it

Your game connection stays direct. QuotaVPN carries only the voice traffic, so region locks stop being the reason you play without a mic.

Transport
Three modes, clearly labelled

Standard, WireGuard and Hysteria2. Each one says in plain words what it spends from, because a faster mode that counts differently is a decision, not a detail.

App routing
Whole device, a list, or everything except

Send all traffic through the tunnel, only the apps you name, or everything except them. The choice is per card and it survives restarts.

Updates
The app keeps itself current

One installer per platform, no admin needed on Windows, signed updates applied for you. The Android APK sideloads once and updates the same way.

Valorant voice chat

Valorant voice chat is not available in some regions, and your ISP or region filter is usually the reason. The app has a page for exactly this: one card, one switch.

What it does
Carries the voice traffic, leaves the game where it is

How it works

Pick a mode to see what a session counts against. The engine is sing-box on both platforms: wintun on Windows, VpnService on Android.

Transport
VLESS on TCP 443 with the class SNI

A TLS handshake that carries a server name from your package's own whitelist, so the ISP files the session under that package.

Nothing for the ISP to read at the start of the connection, which is why it is the raw-speed option.

QUIC-style and fast, with the same server name as Standard.

General quota

ISPs read SNI off TCP only, so a UDP session is counted as general traffic.

Questions

What does QuotaVPN actually change?

Your ISP decides which quota a connection counts against from the TLS handshake at its start. QuotaVPN gives each connection a server name from the package you picked, so the session lands in that bucket instead of your general quota.

What is the Valorant voice chat helper?

Valorant voice chat is not available in some regions. The helper routes just the voice traffic through QuotaVPN while your game connection stays direct, so you can talk in game without moving the match itself onto the tunnel.

Does it work with any ISP?

It is built for ISPs that sell your line in quota buckets, where gaming, streaming and general traffic are counted separately. On a normal line it still works as a plain VPN.

Do I need an account?

No. There is no sign up and no account. You add the server address and the profile your server gives you, and the app connects.

Is the Android build a real app or a wrapper?

It is a native VpnService app with the same Rust core as the Windows build, including per-app routing, a Quick Settings tile and Always-on VPN support.
